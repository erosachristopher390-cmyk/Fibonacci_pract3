# Fibonacci_pract3
Mi programa consiste en generar la serie de Fibonacci utilizando el lenguaje de programación Python.

La serie de Fibonacci es una secuencia numérica en la que cada número se obtiene sumando los dos anteriores. Comienza con los números 0 y 1, y continúa con 1, 2, 3, 5, 8, 13 y así sucesivamente.

En el programa, el usuario puede elegir cuántos números desea generar. Después, mediante un ciclo for, se calculan los valores de la serie y se muestran en pantalla. También se mide el tiempo de ejecución para conocer cuánto tarda el programa en realizar el cálculo.

Finalmente, el código se sube a un repositorio público de GitHub para que otras personas puedan consultarlo y ejecutarlo.
